Condicionales en Scratch

Aprende a programar decisiones lógicas en tus objetos usando bloques "si ... entonces", "si ... si no" y sensores interactivos para responder al usuario y al entorno.

💡 ¿Qué son las estructuras condicionales?

Las estructuras condicionales permiten que un programa evalúe si algo es verdadero o falso, y tome una decisión en consecuencia. Son la base de la inteligencia lógica de cualquier software o juego.

si <condición> entonces si <condición> si no ¿tocando [objeto / color]? ¿tecla [espacio] presionada? ( [puntos] > [50] ) ( <condición 1> y <condición 2> )
