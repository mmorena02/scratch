# Portal de Programación con Scratch

Sitio con fichas interactivas para enseñar programación por bloques en 7.º año.

**En línea:** https://mmorena02.github.io/scratch/

Autor: **Mario Morena** — Profesorado de Informática, CeRP del Centro (Florida, Uruguay).

## Qué contiene

| Página | Qué es |
|---|---|
| `index.html` | Portada con la secuencia de clases y el panel docente |
| `scratch1.html` a `scratch4.html` | Fichas interactivas de las clases 1 a 4, con desafíos por niveles y reporte descargable |
| `recursos.html` | Los recursos seleccionados para el tema, con fuente, licencia y uso previsto |
| `infografia.html` | Infografía propia de las cuatro ideas para programar, y video de apoyo embebido |
| `formulario.html` | Instrumento de recolección de datos, código QR y cartelería de difusión |
| `ciudadania.html` | Recurso interactivo sobre huella digital (CC BY-SA 4.0) |
| `acerca.html` | Autoría, licencias, fuentes, accesibilidad, datos y declaración de uso de IA |
| `err404.html` | Página para rutas que no existen |
| `assets/` | Hoja de estilos común, script común e infografía en SVG y PNG |

## Accesibilidad

Todas las páginas tienen enlace para saltar al contenido, navegación por teclado con foco visible,
textos alternativos y el botón **Ver mejor**, que permite agrandar la letra, pasar todo a mayúsculas
y activar fondo negro. La preferencia queda guardada en esa computadora.

## Datos

El sitio no envía datos a ningún servidor. El avance de cada estudiante se guarda en el
almacenamiento local del navegador de esa computadora. No se pide cédula de identidad: se usa un
código de estudiante formado por las iniciales y el número de lista. Los registros se borran desde
el panel docente de la portada.
